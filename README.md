# NUMRUSH 🎮

NUMRUSH is an interactive number-based web game designed to test and improve the player's calculation speed, concentration, and reaction time.

## 🎯 Features

- Interactive number-based gameplay
- Score tracking
- Timer-based challenges
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

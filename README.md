# NUMRUSH 🎮

A web-based number game designed to test calculation speed,
concentration, and reaction time.

## Features

- Number-based gameplay
- Score tracking
- Timer-based challenges
- Interactive user interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing.

## Project Structure

NUMRUSH/
├── index.html
├── style.css
└── script.js
